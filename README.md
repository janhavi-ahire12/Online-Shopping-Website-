# Minimal Online Shopping System

A small React + Vite website for the Jira Agile/DevOps practical.

## Features
- User Registration (demo form)
- User Login (demo form)
- Search Products
- Add to Cart and cart total
- Simulated Online Payment (no real payment processing)

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## DevOps
GitHub Actions runs `npm install` and `npm run build` on pushes and pull requests.

Note: Login and registration are demo-only and do not save data. Payment is simulated.
